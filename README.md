# Resume Builder

A fully functional, production-ready Resume Builder web app built with Next.js 15, TypeScript, Tailwind CSS, and shadcn/ui components.

## Features

**Multi-Step Form Wizard**
- 5 intuitive steps: Personal Info, Experience, Education, Skills/Projects, Summary
- Smooth animations with Framer Motion
- Progress bar and navigation
- Auto-save to localStorage

**Live Preview Pane**
- Real-time updates as you type
- 3 stunning templates: Minimalist, Modern, Creative
- Theme switcher (light/dark mode)
- Customizable color picker
- Fully responsive design

**PDF Export**
- One-click PDF download
- Print-optimized layouts (A4)
- High-quality, professional output

**Data Management**
- Pre-filled example data
- Add/remove sections dynamically
- JSON export/import
- Persistent localStorage

**AI-Powered Features**
- Resume scoring (0-100 with detailed feedback)
- Job description tailoring
- Content suggestions (bullet points, summaries)
- Keyword optimization

## Tech Stack

- **Next.js 15** - App Router with TypeScript
- **Tailwind CSS** - Utility-first styling
- **shadcn/ui** - Beautiful UI components
- **React Hook Form** - Form management
- **Zod** - Schema validation
- **Framer Motion** - Smooth animations
- **react-pdf** - PDF generation
- **localStorage** - Data persistence
- **Google Gemini AI** - Free AI-powered resume analysis and suggestions

## Features in Detail

### Templates
- **Minimalist**: Clean, simple design
- **Modern**: Professional with colored accents
- **Creative**: Two-column layout with visual elements

### Form Validation
- Real-time validation with Zod
- Error messages for all fields
- Prevents progression until valid

### Auto-Save
- Automatically saves to localStorage
- Data persists across sessions
- No data loss on refresh

### PDF Export
- Professional PDF output
- A4 format optimized
- Includes all sections
